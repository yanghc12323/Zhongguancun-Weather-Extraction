# 中关村天气数据工具设计

已依据 2026-10-14 的可行性评估及用户“开始推进”的授权确定实现方案。

选择公开结构化 API，而不是天气网页解析或需要账户的气象站接口。采用 Open-Meteo 固定模型 ECMWF IFS，支持切换 ERA5。用正式区域 722 个 GCJ-02 点的算术中心作为代表点，迭代反解到 WGS84 后请求；记录返回格点及转换数值残差。转换是公开近似算法的数值反解，残差不代表官方测绘精度。

默认窗口为北京时间 [2026-03-02 00:00, 2026-05-25 00:00)。请求前后各一日缓冲。小时表按 [t,t+1h) 定义：气温等瞬时量使用 t 的记录，降水使用 t+1h 的前一小时累计。半小时瞬时特征沿用该小时起点值；默认仅保留不可跨半小时求和的小时雨量及其区间。显式开启 uniform 才增加均分的半小时估计雨量。日降水从小时区间汇总，确保跨日边界和总量守恒。

Python >=3.10，仅使用标准库。独立包、命令行、中文 README、字段字典、离线单元测试、GitHub CI、原始缓存和元数据。输出包含 2,016 小时、4,032 半小时、84 日的数据及质量报告。另提供 CSV 多对一时间连接，匹配现有 slot_start；不依赖单车原始数据或开发者绝对路径。数据下载目录和本地验证材料不进入代码包。

验收：公开坐标测试向量通过；小时/半小时/日降水边界与守恒测试通过；全期真实请求通过；离线缓存重跑与重新定位代码目录后可运行。来源为区域格点天气估计，当前产物用于事后分析，不能直接充当提前预测时已经可得的天气。
